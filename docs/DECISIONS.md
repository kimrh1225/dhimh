# 설계 결정 기록 및 미확정 항목

## 채택한 구현 가정 (원문 명시 아님)

| ID | 제안 | 이유 | 대안·손실 |
|---|---|---|---|
| ADR-01 | Next.js+TypeScript 단일 웹 앱 | 빠른 MVP 및 서버 API 통합 | React+Express 분리도 가능하지만 개발 부담 증가 |
| ADR-02 | 브라우저 IndexedDB(Dexie) 우선 | 로그인·서버 DB 없이 버전 저장 | 공유/동기화/복구/기기 이동 불가, 브라우저 정리시 유실 |
| ADR-03 | LLM 서버 호출+strict JSON Schema | 구조화 결과 및 비밀키 보호 | 모델 지원·스키마 제약·호출 비용 확인 필요 |
| ADR-04 | 총 6개 루브릭 | 원문의 질문/가설/방법/변수/실행성을 유지하고 결과 해석을 분리 | 분야별 고급 기준은 8주 범위 밖 |
| ADR-05 | 공개 로그인 및 서버 DB 제외 | 8주 위험 감소, 개인정보 서버 보유 축소 | 실사용·협업 서비스에는 부적합 |
| ADR-06 | 비교평가 A/B/C는 앱 밖 절차 | 핵심 검토/개선 기능 우선, 실험조건 관리 | 비교평가 과정에 수작업 소요 |
| ADR-07 | 한국어 UI, 비확정적 피드백 | 원문 대상·AI 역할 반영 | 다국어 MVP 제외 |
| ADR-08 | 실제 모델 ID는 환경변수 | 모델 변경/호환성 검증 유연성 | 배포자 설정 필요 |
| ADR-09 | 1단계 패키지 설치와 잠금 파일은 pnpm 사용 | 현재 실행 환경에 npm 실행 파일이 없고 pnpm 11.25.0이 제공됨; 의존성은 정확한 버전으로 고정 | `npm install`로 설치하면 별도 package-lock이 생성될 수 있음. 이후 단계에서 패키지 관리자 통일 검토 필요 |

## 구현 전 확인해야 할 항목(막힘이 아니면 기본값으로 진행)

1. **정식 서비스명**: 원문 `(앱 이름)` 미정. 우선 `R&E Research Plan Feedback` 작업명으로 둔다.
2. **실제 OpenAI API 접근**: 사용자가 키, 과금 권한, 지원 모델명을 설정해야 함. 미설정 시 mock UI만 시연.
3. **공개 배포 필요 여부**: 현재는 로컬/제한된 데모로 가정. 공개 웹 서비스라면 인증/남용 방지/운영 정책을 별도 범위로 재산정.
4. **학생/미성년자 실제 자료**: 동의 범위 및 기관 요구 절차가 정해지기 전 실제 개인정보/비공개 연구 내용 수집하지 않음.
5. **평가자와 연구 사례**: 확보되지 않은 상태. 실제 학생·전문가 참여 결과를 예측해서 작성하지 않음.
6. **앱의 비교 기능**: 원문은 '수정 전후 계획 비교' 필수, 'ChatGPT 방식간 자동화된 비교 UI'는 요구하지 않으므로 보류.

## 변경 관리

- 요구사항을 바꾸면 PRD/관련 명세/테스트/원문 추적표까지 함께 수정.
- 모델·가격·프레임워크 버전 정보는 빠르게 바뀔 수 있으므로 실제 초기화 시 공식 문서와 설치된 SDK API를 확인하여 구현.
- 실증 결과가 없는 설계 주장(유용성·정확성)은 가설 수준으로 유지.
