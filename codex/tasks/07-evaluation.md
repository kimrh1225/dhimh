# 단계 07 / 7주 — 비교평가 리허설

**읽을 문서**: `docs/EVALUATION_PLAN.md`, `docs/AI_SPEC.md`, `docs/TEST_PLAN.md`, `docs/DECISIONS.md`.

**Codex에게 전달할 지시**:

연구계획서의 A(일반 ChatGPT), B(구조화된 ChatGPT), C(앱) 비교를 위한 **오프라인 연구 진행 자료만** 준비하세요. 합성 연구계획 6~10건(분야/문제 유형 다양), 예상 문제(gold issue) 초안 작성용 표, 평정표 CSV 빈 템플릿, A/B 조건의 공정한 프롬프트 텍스트 및 실험 실행 체크리스트를 `evaluation/`에 만드세요. 골드 정답 초안은 평가자 확인 전 확정하지 말고 구분하세요. 학생/평가자·모델 실행 결과·점수·통계 수치를 날조하지 마세요. 필요하면 순서 랜덤화 방법과 익명 조건 ID 생성 스크립트를 제안하되 앱의 P0 기능을 흔들지 마세요.

**완료 확인**:
- 세 조건 입력 정보가 최대한 일치하고 모두 원문 R&E 계획을 활용.
- 정확성, 실행 가능성, 불확실성, 학생 수정 활용성의 자료수집 표가 존재.
- 가상 인터뷰 및 합성 케이스와 실제 데이터 구별이 명시.
- 실제 ChatGPT/API 자동 실행 없음, 학생 정보 없음.

**금지**: 참가자 응답·평가 점수·성과 결과 생성, 비용 발생 AI 호출, 자동 실험 앱 범위 확장.

**보고/정지**: 생성한 자료 및 사람의 평가가 필요한 부분을 밝히고 종료.
