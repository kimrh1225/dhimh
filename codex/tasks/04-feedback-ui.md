# 단계 04 / 4주 — 피드백 UX

**읽을 문서**: `docs/SCREEN_SPEC.md` S3, `docs/USER_FLOWS.md` F2, `docs/AI_SPEC.md`, `docs/PRD.md` FR-03~05.

**Codex에게 전달할 지시**:

계획 v1 또는 선택된 버전의 AI 검토 버튼, 매 요청마다 외부 전송 고지/동의 확인, 로딩·실패·재시도 UI를 만드세요. 검증된 피드백을 리뷰 ID와 `planVersionId`에 묶어 브라우저에 저장하고 6개 항목별로 status, 근거 인용, 이유, 스스로 할 수 있는 조치, 비판적 질문, 불확실성을 표시하세요. 전체 비판적 질문과 주의 사항도 보여 주세요. `insufficient_information`, `not_applicable`는 별개 문구로 표현하세요. 새로운 분석 결과가 생겨도 과거 리뷰는 덮어쓰지 마세요.

**완료 확인**:
- 동의 없이는 요청 불가. 클릭 반복해도 로딩 중 중복 요청 없음.
- 리로드 뒤에도 리뷰 카드 6개와 질문 표시.
- 서버 실패 시 입력/이전 리뷰 보존, 재시도 가능.
- 키보드 탐색·필드 레이블·상태 색 외 텍스트가 동작.
- mock E2E 통과.

**금지**: 학생을 대신한 자동 연구계획 수정, 합격/불합격 최종 판정 점수, 실제 모델 유료 호출.

**보고/정지**: 스크린 및 테스트 점검 결과를 보고하고 종료.
